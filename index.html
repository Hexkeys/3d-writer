03 / MACHINE

Machine profile

Bambu A1 review mode — not printer-ready

This export contains only basic XY/Z motion lines. It deliberately does not add an assumed Bambu start sequence, homing, bed leveling, heating controls, or end sequence. Do not send this text file to the printer as-is.

Calibration order: (1) Confirm the pen is mounted at the FRONT of the nozzle. (2) Measure the pen tip's X and front/back Y displacement from the nozzle tip. (3) Measure the vertical pen-tip offset and safe up/down heights with the machine safely powered down / under qualified supervision. (4) Enter the values below, verify the coordinate signs against the A1's documented coordinate directions, and inspect the compensated nozzle path. (5) Only then acknowledge calibration. This software cannot sense or auto-measure the physical offsets.

The initial 180 × 180 mm software envelope is a cautious placeholder, not a verified map of the A1's wiper, cutter, clips, frame, or pen-holder clearance. The A1 coordinate convention and firmware workflow must be confirmed independently.

Bambu Studio file wrapper

Select a .gcode.3mf template exported from Bambu Studio using the A1 profile. The app replaces the plate G-code while preserving the package structure. This makes the file importable in Studio; it does not validate the machine commands or make the file safe to run.

No Bambu Studio template selected.

Fine-tune pen offsets

Offsets describe the PEN TIP relative to the NOZZLE. The pen is mounted forward of the nozzle; Y is the front/back axis. G-code compensates the nozzle motion in the opposite direction so the pen tip traces the requested drawing. Confirm whether forward is positive or negative Y on your A1 before using any export. Use measured values, never estimates.

Machine safety

Generic output is not verified for Bambu firmware. The A1 review profile exports a motion-only text file, not a complete printer job. Neither profile verifies physical clearances or makes a real printer safe to operate.
